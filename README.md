# Football Mini Project

This project analyzes an international football match results dataset using Python and Pandas.

## Tasks Completed

- Read the dataset into a Pandas DataFrame
- Checked for missing values
- Removed missing value entries
- Counted the number of tuples in the dataset
- Counted the number of unique tournament names
- Converted the date column to timestamp format
- Counted the number of matches played in 2018
- Calculated home team wins, losses, and draws
- Created a pie chart for wins, losses, and draws
- Created a pie chart for the neutral venue column
- Counted the number of unique team names

## Dataset

The dataset file used in this project is:

results.csv
